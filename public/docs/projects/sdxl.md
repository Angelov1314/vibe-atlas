# Stable Diffusion XL

拥有大量微调模型与控制插件的通用本地图像生成底座。

## 项目信息

- 类型：本地模型
- 分类：文生图 / 图像编辑 / 局部重绘
- GitHub：https://github.com/Stability-AI/generative-models
- 官网：https://github.com/Stability-AI/generative-models
- 代码许可：MIT (repository code)
- 权重许可：CreativeML Open RAIL++-M
- 权重分类：restricted-open-weights

## 许可说明

权重使用含使用限制的 Open RAIL++-M；下游 LoRA 和微调模型需单独核对。

## 本地部署

使用隔离 Python 环境，按官方 README 安装与下载指定权重；安装前审阅依赖和许可证。

以上是官方安装方向，不代表已在本机执行或验证。详情页可下载包含完整检查步骤的 Codex 部署任务。
