# CesiumJS

把地形、影像与海量地理数据组合成可交互的 3D 地球。

## 项目信息

- 类型：创作工具
- 分类：地理空间与数字地球
- GitHub：https://github.com/CesiumGS/cesium
- 官网：https://cesium.com/platform/cesiumjs
- 代码许可：Apache-2.0
