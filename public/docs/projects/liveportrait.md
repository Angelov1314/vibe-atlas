# LivePortrait

用驱动视频让静态人物或动物肖像产生自然表情与运动。

## 项目信息

- 类型：本地模型
- 分类：人像动画
- GitHub：https://github.com/KlingAIResearch/LivePortrait
- 官网：https://github.com/KlingAIResearch/LivePortrait
- 代码许可：MIT
- 权重许可：MIT core; InsightFace dependency restricted
- 权重分类：mixed-dependency-restrictions

## 许可说明

核心代码与权重采用 MIT，但默认 InsightFace 模型有非商业限制；完整流水线不可只看主仓库许可。

## 本地部署

使用隔离 Python 环境，按官方 README 安装与下载指定权重；安装前审阅依赖和许可证。

以上是官方安装方向，不代表已在本机执行或验证。详情页可下载包含完整检查步骤的 Codex 部署任务。
