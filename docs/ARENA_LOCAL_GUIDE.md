# Arena 与本地部署说明

更新日期：2026-11-03。本文保存从界面迁出的评测规则、填写说明、运行边界和部署解释。页面只保留任务、实际状态、必要输入与确认。

## 模型 Arena

Arena 比较同一任务、同一提示词、同一输入和同一生成协议下的真实输出。模型身份在投票前隐藏，投票后揭晓。目录热度用于发现项目，不参与生成质量投票。

### 从提交到盲评

1. 选择目录里的两个不同模型，记录精确权重 revision 或代码提交 SHA。
2. 使用相同提示词、输入、参数、硬件和推理后端生成两份输出，保留实际运行日志。
3. 上传真实媒体文件与生成记录，状态首先为待审核。
4. 指定管理员核对授权、版本、原始输入、参数和媒体内容。
5. 已核验且可比较的样本进入随机分配的盲评；上传者不能评价自己的样本。
6. 评委选择 A、B、不分上下或都不好。系统保存评价后揭晓模型身份。

管理员未配置时，上传只能保存为待审核。核验前不会进入对战，也不产生质量分。没有真实样本或对战时，分数保留空值，不填演示成绩。

### 上传字段

| 字段 | 要求 |
| --- | --- |
| 模型与 revision | 选择两个不同模型，填写实际使用的权重版本或代码提交，不用模糊的“最新版”。 |
| 输出文件 | 每个文件最多 12 MB。图像使用 PNG / JPEG / WebP，视频使用 MP4 / WebM，音频使用 WAV / MP3。 |
| 提示词 | 保存实际发送给模型的完整提示词，包括语言、约束和歌词等。两份输出使用同一提示词。 |
| 负面提示词 | 可选；两份输出保持一致。 |
| 输入 SHA-256 | 对需要输入的任务必填，64 位十六进制摘要。多个文件使用可复核的输入清单摘要，并在日志解释清单规则。 |
| 统一协议 | 分辨率、时长、帧率、采样率、步数、种子、引导强度、采样器、调度器、精度、硬件和后端版本适用于 A 与 B。 |
| 不适用参数 | 原生不适用的采样项填 `0` 或 `native`，并在运行记录解释。不能因此隐藏真实差异。 |
| 生成记录 | 保留权重来源、完整参数、实际运行记录和输入核验方法。不要包含密钥或私人信息。 |
| 工作流 SHA-256 | 可选，用于对应确切工作流文件。摘要证明一致性，不能单独证明模型来源。 |

不要对一方单独做美化或有利的后处理。清除能直接泄露模型身份的水印、片头和文件内文本元数据，同时保留可供管理员核验的原始生成记录。涉及人物、声音和输入素材时，上传者应有相应授权，并确认可以公开提示词与输出。

上传频率上限为每分钟 2 组、每天 8 组。触发人机验证后，完成验证并重新提交。具体错误和服务状态以页面及 API 返回为准。

### 3D 与其他任务的比较边界

3D 任务当前上传固定相机的转台视频，需记录统一的相机轨迹、焦距、光源、背景、材质和渲染器。该结果评估渲染表现，不等同于几何精度、拓扑质量或可编辑性评测。

不同分辨率、时长、精度、输入和后处理不会混排。语音识别、音频理解、语言生成、视觉理解、OCR、文本嵌入和图像嵌入任务需要独立协议，目前不开放相同的媒体盲评流程。

### 怎样理解分数

- **起始热度**来自目录关注数据，帮助发现项目；它不是模型效果分。
- **社区偏好**只在真实对战后计算同一协议内的暂定 Elo。
- 当前使用顺序 Elo 估计，未提供统计置信区间。
- 未连通的对战组之间不能直接比较绝对分数。
- 不同协议不能直接比较分值；协议名称相似也不意味着协议相同。

防刷使用已验证身份、重复评价限制、频率限制、风险权重、必要的人机验证和隔离审核。同一已验证身份对同一提示词与模型组合只计一次。新账号与共享网络本身不等于机器人。风险评价可以等待复核；样本撤销核验后，相应票据不再用于质量计分。

未配置的跨账号关联、设备关联和人机验证服务不会被视为已经启用。完整起始分、社区分和风险调整规则见 [ranking-policy.md](./ranking-policy.md)。

### 管理员审核

管理员需要核对生成来源、版本、参数、输入授权和实际输出，确认公开媒体不直接透露身份。审核理由需记录核验依据；拒绝或撤销时记录原因。页面中保留明确的复核确认和独立的通过、拒绝操作。

## 本地部署

浏览器通过一个 Python companion 与用户自己的电脑配对。项目自带 companion 使用 Python 标准库，要求 Python 3.10 或更新；完整源码可在 `public/downloads/atlas_companion.py` 审阅。用户电脑需要另行安装适用的 Docker 与 Ollama。

### 连接电脑

1. 从本地部署页面下载 companion。
2. 在文件所在目录打开终端，复制页面生成的 macOS / Linux 或 Windows 命令。命令包含当前页面的精确 Origin。
3. 保持终端运行，把终端显示的随机令牌粘贴到页面。
4. 连接后读取实际探测到的操作系统、GPU、Docker 与 Ollama 状态。

连接本身不会安装软件、拉取模型或运行 Docker 配方。配对令牌只保留在当前页面内存，刷新后清除。

companion 固定监听 `127.0.0.1:4317`，验证请求的 Host、页面 Origin 和 Bearer 令牌；它不接受任意地址或任意 shell 命令。浏览器可能要求额外允许本地网络访问。若连接失败，核对 companion 是否运行、页面 Origin 是否一致以及浏览器网络权限；更详细步骤见源码包中的 `public/downloads/LOCAL_SETUP.md`，网站上可从「安装说明.md」下载。

断开页面连接会清除页面令牌，不停止已有后台任务或容器。关闭网页、停止 companion 后，已有 Docker 容器仍可能继续运行。

### 当前支持的三个配方

| 配方 | 作用 | 默认本机端口 | 需要知道 |
| --- | --- | --- | --- |
| Open WebUI | 本地模型聊天界面 | 3000 | 首次使用需建立管理员账号；Linux 的回环 Ollama 未必可由 Docker 网关访问。页面里的本地问答直接使用回环 Ollama。 |
| n8n | 可视化自动化工作流 | 5678 | 使用本机 HTTP 开发配置，首次访问建立账号；公网 webhook 不能直接访问回环地址。 |
| Qdrant | 向量数据库 | 6333 | 只开放本机 HTTP，不开放 gRPC；初始配置用于本机试用，未配置生产鉴权。 |

配方使用持久数据卷。GPU 模型的部署任务可以从目录项目详情获取；目录里存在项目不等于 companion 已支持其自动安装。

### 生成和确认计划

先连接电脑，再选择配方并生成计划。页面呈现镜像、容器、端口、数据卷、许可和下载状态，并可展开完整执行参数。点击 **完整计划.md** 可保存所有运行条件、官方来源、完整参数、有效期和计划 SHA-256。

计划有 10 分钟有效期。逐项核对后勾选确认，在本机拉取并启动。计划 ID 与摘要一起提交；未确认、过期或摘要不一致的计划不得执行。

部署条件：

- 部署前尚未拉取，镜像下载大小未知，确认后会访问官方仓库并占用本机磁盘。
- 初次拉取使用官方 tag，内容可能变化；拉取后解析官方仓库 `RepoDigest`，实际启动固定到对应 SHA-256，并写入回执。
- 同名容器存在时停止部署并返回检查结果，不删除、不替换、不自动启动旧容器。
- 只支持可访问的本机 Docker socket，不接受远程 Docker context。
- Open WebUI 密钥在本机随机生成并保存为 `0600` 文件，经进程环境传入；计划和回执不包含密钥值。其他配方不接受浏览器提供的任意环境变量。
- 执行使用受限参数数组，不经过 shell，也不执行模型回答里的命令。

任务状态从实际本机结果读取：等待检查、拉取、启动、健康检查、成功、需要本机检查、失败或发现已有容器。成功状态依赖健康检查；用户仍需检查服务是否符合自己的任务需要。回执保留镜像摘要和执行参数，不含生成的密钥值。

### 本地问答

问答先在目录检索符合任务和许可约束的项目，再把相关来源交给本机 Ollama 解释。页面仅列出本机已有的模型权重，排除 cloud 标签和远程模型，不自动拉取模型或调用云端模型 API。

如果当前目录没有满足任务约束的候选，系统明确返回没有匹配，不扩大到无关任务。商业使用筛选只筛出明确的宽松许可候选，仍需核对模型权重、训练数据与第三方依赖的条件。回答保留来源以及本次检索范围。

模型输出用于说明和比较。部署始终使用独立的受限配方、可检查计划与用户确认，不能把聊天输出当作已完成部署的证据。
