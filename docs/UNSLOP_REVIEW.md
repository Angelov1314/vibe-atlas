# 界面迭代与设计依据

Vibe Atlas 采用白色平面目录、系统字体、可追溯的项目来源与明确的许可状态。长说明保留在 Markdown，卡片展示名称、用途和必要数据。具体规范以 DESIGN.md 为准。

设计原则参考 Damir Sokolovsky（[@heydamir](https://github.com/heydamir)）的 [unslop](https://github.com/heydamir/unslop)，其 skill 文本采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；本项目适配其审核原则用于中文目录界面，未原样分发完整 skill。另参考 [Impeccable](https://github.com/pbakaus/impeccable)。

本文保留设计依据和署名，不发布内部截图审查记录。
