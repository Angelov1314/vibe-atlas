# Vibe Atlas 使用指南

## 目录

当前目录包括 14 个创作工具大类、92 个细分分支、159 个工具，以及 40 个本地模型、34 种任务。2026-11-03 新增 75 个仓库，使用 Firecrawl、Tavily 检索公开 X 线索，并从 GitHub 主源核验。原有 84 个工具与模型的历史指标保留原采集日期，不是全目录实时刷新。新增条目中 23 个有明确 X 发现线索，其余为同类补充；X 热度仍未采集完整观察窗口。

顶部切换“创作工具 / 本地模型”。搜索使用中英文关键词与用途扩展；切换目录类型会保留搜索词。左侧或手机横向分类栏可选择大类，细分分支在桌面展开、手机使用下拉框。

书签保存在当前浏览器；更换浏览器不会自动同步。项目卡片的加号用于对比，最多同时比较三个项目。搜索快捷键为 macOS 的 Command+K 或 Windows / Linux 的 Ctrl+K。

每个项目有一张真实项目展示图或官方仓库预览，以及一句用途介绍。图片归属、许可补充、硬件说明、安装方向和原始来源记录可以在详情页下载为 `.md`，也已经包含在交付包的 `public/docs/projects/` 中。官方远程预览图需要网络可达，前排重点项目另有本地素材；加载失败时会显示明确回退。

## 三类评分

### 仓库热度

这是发现排序，按可用的 GitHub / X 信号计算。当前 X 未接入，缺少完整 30 日增长历史，因此必须同时查看数据覆盖率。默认“精选”是编辑顺序；“仓库热度”与“GitHub Stars”是各自独立排序。

GitHub 上受关注的代表项目不等于某分类全网第一，仓库星数也不能作为模型生成质量。具体权重和缺失处理见 `public/downloads/RANKING_POLICY.md`。

### 社区评价

使用真实登录身份，每账号每项目一份最新评价。重新评分会替换原评价。服务器计算风险权重、限流、后验与置信区间，客户端自报权重不会被采用。社区排序使用置信下界，避免少量极端评分直接排在最前。

未评价项目保持空白。当前启发式风控并不是能识别所有机器人或多账号协同的保证；Turnstile 和审核配置、真实数据校准仍需运营者完成。异常评价可以在项目详情申请复核。

### Arena

只比较同一协议内经过审核的真实生成输出；左右顺序由服务器安排。没有真实样本时显示空状态，不使用项目截图充当评测。协议包含任务、提示词、版本、生成参数、算力预算和输入证据。具体提交与审核说明见 `ARENA_LOCAL_GUIDE.md`。

## Atlas 检索与本地模型问答

“问 Atlas”默认使用目录检索与规则约束，不连接远程生成模型。它根据任务和许可条件返回实际目录项目。聊天文本中的推荐属于目录决策支持，不能当作已执行部署或实测兼容性。

要使用生成式解释，在“本地部署”连接 companion，再选择电脑上已有的 Ollama 本地权重。它只接收检索后的目录上下文；不会自动下载权重或运行回答中的命令。

## 本地部署

项目详情的“部署任务”下载可交给 Codex 的 Markdown。Open WebUI、n8n、Qdrant 另有经过审核的 Docker 配方：先连接电脑、生成计划、核对镜像 / 端口 / 数据卷 / 许可 / 命令，再明确确认执行。其他项目仍需要依官方文档检查硬件与运行环境。

浏览器不能静默安装电脑软件。companion 的配对令牌只留在页面内存；服务绑定回环地址，拒绝不匹配的 Origin / Host / token、任意命令和远程 Docker context。完整安装、停止和数据保存方法见 `public/downloads/LOCAL_SETUP.md`。

## 权重计算器

文档页保留一个可展开的计算器。它使用模拟账号，不写入榜单；起始热度固定为 70，账号年龄代表首次进入本站后的天数。可改变人数、评分和重复行为，观察单票权重、有效证据与后验。公式与局限在评分政策中。

## 访问问题

已发布站点保持所有者私有访问。完整诊断记录见 `ACCESS_TROUBLESHOOTING.md`。ZIP 可以独立在本地启动，不依赖正式站点的登录回跳。
